# rmmarques-releases
Versões do tema rmmarques para WordPress (pacotes sereno.zip e atualização automática)

Cada versão fica em [Releases](https://github.com/rafamarquesd/rmmarques-releases/releases), com o arquivo `sereno.zip`. Sites com o tema 2.1.0 ou mais novo procuram as versões novas aqui e se atualizam sozinhos.
